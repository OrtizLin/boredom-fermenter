# 無聊發酵機 Boredom Fermenter

> 孩子喊「我好無聊」時，不給答案，只當陪伴者——把無聊發酵成一場創意任務，用家裡現有的東西玩起來。

參加 **OPEN LAB AI Build Challenge**（AI 郵報）。投稿截止 **2026-11-27 23:59（台北時間）**，決賽 **2026-12-05 台北瓶蓋工廠**。
本資料夾是參賽作品本身，**尚未報名、尚未投稿**。

## 想做什麼

靈感來自真實經驗：客廳有一個「靈感百寶箱」，裡面只有黏土、廢紙盒、幾顆球、彩繪筆和積木。
孩子喊無聊、3C 時間結束後的空白時間，大人不給答案，只陪著問問題，無聊就變成了動力。
這個點子來自 Otis 的國語日報家庭版文章〈孩子沒3C就喊無聊〉，沒有編造其他家庭細節。

無聊發酵機就是把這個做法做成一個網頁：家長勾選家裡現有的材料、時間和孩子今天的能量，
按「開始發酵」，就得到一張可以直接玩的任務卡——任務名稱、故事、步驟、陪伴者提問、安全提醒和計時器都在上面。

## 怎麼操作

零後端、零建置步驟、零安裝，評審打開連結就能用。

```bash
cd competitions/openlab-ai-build-challenge
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000/
```

也可以直接雙擊 `index.html` 開啟（Chrome / Edge / Firefox / Safari 皆可；收藏功能用 localStorage，`file://` 下在多數瀏覽器仍可運作，建議用上面的 http.server 開啟最穩）。

操作流程：

1. 選孩子年齡（3–4／4–6／7–9 歲，預設 4–6 歲）、可用時間（15／30／60 分鐘）。
2. 勾選家裡現有的材料（黏土、廢紙盒、球、彩繪筆、積木、毛巾、紙杯、舊報紙；預設勾選靈感百寶箱的 5 樣，至少勾 2 樣）。
3. 選今天的心情／能量（想動一動／想靜靜做／不一定）。
4. 按「開始發酵」，得到一張任務卡；不喜歡按「再發酵一次」換一張；喜歡按「⭐ 收藏這個任務」。
5. 按「開始計時」開始倒數計時，可暫停、重設；時間到會顯示「時間到！」。

## 核心功能與使用情境

- **任務卡**：任務名稱（例如「幫小汽車蓋一座會塌的賽車場」）、2–3 句任務故事、需要材料（只用勾選的材料）、3–5 步具體步驟、陪伴者提示（家長不給答案、只問問題，例如「你覺得賽車場還缺什麼？」）、安全提醒、計時器。
- **真的有邏輯的組合引擎**（`engine.js`，不是寫死的幾張卡）：40 張任務模板，依材料、時間、年齡、能量篩選組合。
  全材料、4–6 歲、60 分鐘、不限能量時有 38 種不重複玩法；預設條件（靈感百寶箱 5 樣、4–6 歲、30 分鐘、想動）有 12 種。
  每張卡有任務編號（例如 `BF-482910`），編號就是隨機種子——在「任務種子」欄位填入同一編號，就會重現同一張任務卡。
- **再發酵一次**：換一個種子、換一張任務卡。
- **收藏任務**：存到瀏覽器 localStorage，可查看、打開、刪除；關掉網頁還在，換一台電腦就看不到。
- **列印任務卡**：可把任務卡印出來，貼在冰箱上。
- **使用情境**：孩子喊「我好無聊」、3C 時間結束後的空白時間、雨天待在家裡、等出門前的空檔。需家長陪同，任務只是建議玩法，請依孩子的實際狀況調整。

## AI 使用方式

分兩層，**沒有 API Key 也能完整使用**：

1. **本地組合引擎（預設，主力）**：`engine.js` 在瀏覽器本機依材料、時間、年齡、能量組合出任務，不連網、不呼叫任何模型、不收費。
2. **選填的 LLM 模式**：在「AI 模式」裡，使用者可在自己的瀏覽器輸入自己的 API Key，可選 MixRoute 或 Gemini，呼叫後用該模型再生成一個任務。
   - MixRoute：OpenAI 相容端點 `https://api.mixroute.ai/v1/chat/completions`，模型請填 MixRoute 模型 ID。
   - Gemini：`https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`，模型預設 `gemini-3-flash-preview`。
   - Key 只存在使用者瀏覽器的 localStorage，絕不寫入任何檔案、不上傳到我們的伺服器（本作品根本沒有伺服器）；Key 只會直接送到使用者自己選的供應商（MixRoute 或 Google），請自行留意該供應商的收費與使用條款。網頁上有「清除已存的 Key」按鈕。
   - 提示詞會要求模型只用勾選的材料、回傳固定 JSON 格式；若模型回傳的材料超出勾選範圍，顯示前會先以勾選材料為準。
   - 沒有 Key 時，按「用 AI 再發酵一個任務」會明確提示先儲存 Key，本地引擎不受影響。

## 第三方來源

- 無第三方程式庫、無外部字體、無外部圖片。字體使用系統字體（PingFang TC、Microsoft JhengHei、system-ui）。
- MixRoute 與 Gemini 僅在使用者自行啟用 AI 模式、輸入自己的 Key 時才會被呼叫；本地模式不呼叫任何第三方服務。
- 任務內容為原創，靈感來源為上述國語日報家庭版文章（作者本人）。

## 目前限制

- LLM 模式需自備 API Key 與自行負擔該供應商的費用；沒有 Key 只能用本地組合引擎。
- 任務為建議玩法，不是教學課綱，需家長陪同、依孩子實際狀況調整；安全提醒不能取代家長的現場判斷。
- 收藏只存在單一瀏覽器的 localStorage，換裝置、清掉瀏覽器資料就會消失；沒有帳號、沒有雲端同步。
- 計時器時間到只會顯示文字，不會發出聲音。
- 任務模板共 40 張，組合雖多，但長期重複玩仍可能遇到重複的模板（不同種子、不同條件會降低重複機率）。
- 規章為草案版本（最後更新 2026-11-11），正式公告可能調整；投稿前請以官方正式公告為準。
